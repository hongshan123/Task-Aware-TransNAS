# Phase 7A：持续学习 Pilot 结果

## 执行协议

在 Qwen3-0.6B、seed 10 上执行 S1（`565 → 1603 → 1501 → 1384`）和 S2（`565 → 1501 → 1603 → 1384`），比较 C0 Full SFT、C1 官方 PaRSP、C2 mask-only、C3 projection-only。C1 正式审计触发约束修正后，增加 C4 严格交集对照。所有条件每个任务训练 50 步，使用相同任务样本顺序、提示格式、优化器预算与 seed。单任务 5 步和两任务 smoke 均通过，随后每条序列的五个条件都完成 200 步。

训练阶段只读各任务 train。全部训练任务和边界 checkpoint 写完后，评价阶段才统一读取 dev；每个任务 dev 50 条记录。两条序列 manifest 和离线功能风险日志都记录 `evaluation_splits_loaded: ["dev"]`、`test_split_files_opened: []`。没有历史 replay、NAS 或 test 访问。

| S1 | C0 Full SFT | 0.35170 | 0.22962 | −0.22962 | 0.00000 |
| S1 | C1 PaRSP | 0.50409 | 0.00592 | −0.00592 | 0.02000 |
| S1 | C2 mask-only | 0.47121 | 0.09401 | −0.09401 | 0.02000 |

两条序列中 C1 的最终 AAA 都数值上明显高于 Full SFT（分别高 `0.15239` 和 `0.20031`），并把平均遗忘从 `0.230/0.324` 降至约 `0.006`。这证明了本 pilot 内相对 Full SFT 的保留优势；单 seed 不支持跨运行统计显著性的判断。C2 单独 mask 也有帮助，但平均遗忘高于含投影的 C1/C3；C3 在 S1 得到最高 AAA，在 S2 与 C1/C2 接近，同时两条顺序上的平均遗忘都很低。C4 的保留指标最好，但 AAA 低于 C1/C3。还需要同时考虑下述新任务获取能力，避免把低遗忘直接解释为更好的学习。

基线 dev 结果为：task565 ROUGE-L/Token-F1/NLL=`0.1945/0.2039/4.1671`；task1603=`0.1596/0.1744/3.3510`；task1501 Accuracy/Macro-F1/Yes-No error/NLL=`0.76/0.4318/0/2.5718`；task1384=`0.88/0.8125/0/1.1019`。各条件最终每任务的 ROUGE-L、Token-F1、Accuracy、Macro-F1、Yes/No 错误率和 teacher-forced NLL 全量保存在 `results/phase7a/pilot_final_task_metrics.csv`。逐阶段指标表为 `pilot_stage_summary.csv`，AAA 曲线见 [pilot_aaa_trajectory.png](../figures/phase7a/pilot_aaa_trajectory.png)。

## 获取与保留的取舍

基础模型四任务 AAA 为 `0.49853`，因此 C1 的最终 AAA 相对基础模型只提高 S1 `0.00556`、S2 `0.00348`；较大的 C1–C0 差距主要体现防止 Full SFT 崩塌，而非所有任务都有较强的新能力增长。最终表中的 Acquisition 只属于最后任务 task1384，不能代表四任务的整体获取能力。四个学习边界的 Acquisition 均值分别为 C1 `0.01000/0.00542`、C2 `0.04319/0.04574`、C3 `0.01907/0.00566`、C4 `−0.01186/−0.00979`（S1/S2；仍为不同 primary metrics 的宏平均）。

task1603 的基础模型 ROUGE-L 为 `0.15964`，不同方法刚学完该任务与序列结束时的分数显示出关键区别：

| 条件 | S1 刚学完 → 最终 | S2 刚学完 → 最终 |
|---|---:|---:|
| C0 | 0.2611 → 0.0068 | 0.3237 → 0.0068 |
| C1 | 0.0802 → 0.0769 | 0.0618 → 0.0618 |
| C2 | 0.1929 → 0.1363 | 0.2031 → 0.1482 |
| C3 | 0.1416 → 0.1503 | 0.0680 → 0.0680 |
| C4 | 0.0527 → 0.0527 | 0.0410 → 0.0464 |

C0 能获取 task1603 能力，却在后续任务中严重遗忘；C2 的获取与保留较均衡；C1/C3 抑制遗忘的同时，这个生成任务的获取分数低于基础模型；C4 的该问题最突出。负 Acquisition 是相对最初基础模型，不等同于该任务本身的训练直接造成下降，因为当前记录没有对尚未学习的任务做每个边界的评价。平均遗忘只测量“学到后的下降”，会掩盖“最初就没有学好”的情况。

C3 的实现仍调用官方 `layer_division_qwen`，保留当前任务 attribution 选层与其他层冻结，只移除层内 neuron/channel mask。因此 C3–C1 是所选层内 mask 的消融；C3–C0 还包含选层/冻结差异，不能把所有收益归因于 projection。各条件沿不同历史轨迹重新归因，选层也并非保证完全相同。需要增加 layer-only 和全层 projection 对照才能进一步分离原因。

C4 在 S1/S2 的有历史保护模块步中，严格交集秩为零的比例约为 `39.8%/51.5%`。因此低遗忘部分伴随着可用更新空间大幅收缩，应把 C4 作为严格约束机制对照，而非当前最佳训练方案。

## 约束、参数更新比例与资源

C1 正式更新审计在两条序列都发现大规模 mask 外更新及历史激活残差，触发 C4。C4 将最大归一化历史激活残差压到 S1 `6.46e-7`、S2 `0`，两条序列都没有超阈值行或 mask 外更新；但共有 1,398/1,332 个模块步被 fail-closed 回滚。实际发生变化的参数比例均值为 C0 `99.99%`、C1/C2/C3 `29.03%`、C4 S1 `9.44%`、S2 `8.33%`。

## 研究问题的回答

PaRSP 在本 pilot 的最终保留指标上优于 Full SFT，但 task1603 的获取仍是主要短板。包含选层/冻结的 projection 条件保留效果较好；当前消融尚不足以完全拆分选层与投影收益。官方 hook 对梯度施加约束，但本地 C1 的实际 AdamW 参数差没有严格满足所审计的 mask 与历史零空间阈值。C4 能满足这些数值阈值，却牺牲了新任务获取与可用更新空间。

功能重要性和保护需求不等价的假设得到本 pilot 的机制证据支持：component rank correlations 随粒度/任务/阶段变化，且精确回滚出现重要性相反的区域；它不是一个普遍的负相关结论。建议下一阶段先扩展 seed/任务顺序并验证风险感知参数分配的最小消融，再决定是否进入 NAS。单 seed、短预算和 dev 上的小样本意味着这些结论是 pilot 证据，不是最终统计结论。
