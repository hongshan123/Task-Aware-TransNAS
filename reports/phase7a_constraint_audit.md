# Phase 7A：PaRSP 约束与优化器审计

## 官方规则落在梯度空间

PaRSP 的联合规则为 `G_new = (G ⊙ M)P`：先用稀疏 mask `M` 逐坐标屏蔽梯度，再右乘历史表示协方差投影 `P`。适配器沿用官方 Qwen 函数及注册顺序，没有在 C1 中偷偷改成严格交集。逐层稀疏 mask 与稠密投影通常不对易：右乘投影后，原本被 mask 清零的输入列可以重新出现非零值。

真实 `optimizer.step()` 还改变约束所作用的对象。AdamW 的解耦 weight decay 会改动有梯度张量的零梯度坐标；动量状态和坐标自适应缩放也会使实际 `ΔW` 不等于投影后的梯度方向。因此 hook 约束梯度并不能单独保证真实参数变化满足同一约束。审计在 optimizer 前后保存实际权重差，并记录投影前后梯度、裁剪后梯度、更新方向差、mask 外更新、`||ΔW X_old||`、投影秩和 bias 更新。

官方 attention channel mask 仅作用于 V 行与 O 输入列；所选 attention layer 的 Q/K 不使用同一通道 mask。FFN mask 落在 gate/up 行及 down 列。Qwen3 的 GQA 具有 16 个 query heads、8 个 KV heads；适配器按共享组映射 query channel 到 KV channel，避免直接索引不同宽度的 V 投影。当前线性投影没有 bias，但审计仍记录 bias 变化。单测覆盖真实 Qwen 形状、官方 hook 顺序、AdamW 后参数差、训练 callback 边界、GQA 映射与空/低秩情形。

官方投影按协方差特征值截断，并至少保留 `int(d × 0.20)` 个低特征值方向；这些方向只是低方差方向，不能一般地称为精确零空间。S1 的 11,550 条有历史投影记录中，10,050 条触发了强制最小保留比例；S2 为 10,350 条。

## 正式 C1 真实更新结果

每条序列有 `77 modules × 50 steps × 4 tasks = 15,400` 条 C1 审计记录。掩码轴适用的 11,000 条记录中，S1 与 S2 均有 11,000 条实际参数变化落在 mask 外；最大 mask 外更新范数比率分别为 `0.80615` 与 `0.79728`。有历史投影的 11,550 条记录中，两条序列的每条记录都超过 `1e-6` 历史激活残差阈值；最大归一化残差分别为 `0.038817` 与 `0.031717`。违规不只是梯度张量上的现象，是真实 optimizer 更新的变化。

预注册 C4 触发条件为 mask 外更新比率大于 `1e-8` 或归一化历史激活残差大于 `1e-6`。C1 在 S1、S2 都触发，故运行 C4。上游 C1 结果完整保留，C4 仅为单独实验条件。

## C4 严格约束对照

C4 将 optimizer 产生的真实更新投影到 mask 允许坐标与历史激活精确零空间的交集；使用 FP64 特征分解、`rcond=1e-12`。若投影后任一模块的归一化历史激活残差仍高于 `1e-6`，则 fail-closed 回滚该模块此次更新。没有历史锚点的首任务不施加历史约束。

| 序列 | 最大历史激活残差 | 超阈值记录 | mask 外更新记录 | Fail-closed 模块步回滚 | C4 实际变化参数比例均值 |
|---|---:|---:|---:|---:|---:|
| S1 | `6.4567e-7` | 0 / 15,400 | 0 / 11,000 | 1,398 | 9.44% |
| S2 | `0` | 0 / 15,400 | 0 / 11,000 | 1,332 | 8.33% |

严格交集秩显示约束代价明显：只看 11,550 条启用历史投影的模块步，交集秩中位数 S1 为 1、S2 为 0，秩为零的记录分别有 4,600 与 5,950 条；最大秩为 78。C4 的真实参数变化比例也低于 C1 的 29.03%。因此 C4 的数值约束成立，但在当前历史样本与稀疏坐标交集下会大量压缩可用更新空间，必须和性能一起解释。

## Smoke、恢复与验证

单任务 smoke 在无历史协方差时仍观察到 AdamW 造成的 mask 外更新；双任务 smoke 触发了与正式 pilot 相同的投影后残差问题。正式 S1/S2 的 C4 首次运行在审计零参数更新时暴露了除零错误，部分输出完整归档在 `C4_attempt1_zero_update_crash_*`；修复零范数处理并加上超阈值回滚后，C4 从独立输出目录完成全部任务。S2 的 C2 首次尝试因共享 GPU 显存压力 OOM，未写失败 checkpoint；失败目录和恢复记录保留，显存空出后 C2 完整重跑。正式访问日志只记录 train 与 dev，test 文件列表为空。

约束测试位于 `tests/test_phase7a_constraints.py`、`tests/test_phase7a_covariance_transfer.py`、`tests/test_phase7a_resume.py` 和 `tests/test_phase7a_data_access.py`。完整 pytest 套件在最终代码后的验证结果记录于实现计划与 pilot 报告。
